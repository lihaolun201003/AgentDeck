# Windows 分屏与自适应布局

恢复原生标题栏、可调整边框和最小化 / 最大化按钮，以支持 Windows 系统贴靠分屏。
顶部「靠右」按钮按当前显示器的可用工作区摆放窗口，避开任务栏，并使用 Qt 逻辑坐标
适配缩放；按钮仅调整 AgentDeck 自身位置，不为其他应用强制指定窗口布局。

宽度小于 720 时使用分类下拉框 + 上方列表 + 下方预览；宽窗口保持分类 / 列表 / 预览三栏。
保留相同控件实例，切换布局不会丢失搜索内容和选中条目。底部新增明确的「复制 Prompt」按钮。

窗口位置、大小、最大化状态经防抖写入配置。呼出时不再强制回到屏幕中央。重启时恢复位置，
若旧显示器已移除，则把位置限制在当前可用桌面内。配置的自定义保存位置也会被记住，避免
测试配置或其他配置文件的后续保存误写到默认配置。

新增窄窗口操作、宽窄切换保持选择、复制后继续显示、呼出位置保持、多屏坐标、配置持久化
及异常值校验测试。界面按 340、440、600、1000 像素宽分别渲染检查。

验证结果：完整自动化测试套件通过；打包 exe 自检通过。在实际打包程序中点击「靠右」后，
窗口贴合当前屏幕右侧并切换为上下布局；原生标题栏、可调整边框、最大化按钮均存在。
实际点击「大步开发」预览同步，点击复制后的剪贴板与文件正文完全一致，面板继续显示。
Windows 分屏菜单本身由系统提供，本次未自动选择系统分屏布局。
