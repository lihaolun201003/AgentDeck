# 白色主题与预览切换修复

修复列表点击新条目后，右侧仍显示上一条 Prompt 的问题。根因是列表没有连接
`currentItemChanged` 信号：搜索刷新和搜索框方向键会主动刷新预览，普通鼠标点击
及列表获得焦点后的方向键只更新选中态。现在通过选中项变化统一更新标题、路径、
正文及收藏状态。

主窗口、搜索框、预览、编辑器、变量框、设置、菜单改为白色 / 浅灰底，搭配深色文字
和蓝色选中态；原生控件使用浅色 Fusion 调色板。

新增鼠标点击、列表方向键、搜索框方向键的预览同步回归测试，以及无搜索结果时清空
预览、恢复结果后再次显示的测试。修复前鼠标及列表方向键用例失败，修复后全部
56 个自动化用例通过。

本次在 `build/white-release` 构建后更新 `dist/AgentDeck` 的程序文件，保留用户的
`prompts/` 和 `data/`。更新前的 Prompt、配置及 exe 备份在 `backups/before-white-*`。

构建时发现 PATH 中 Poppler 的 `icuuc.dll` 被误收集，缺少 Qt 所需的 Windows ICU
导出函数，导致打包程序导入 QtCore 失败。spec 现优先从 Windows System32 解析系统
依赖；build.bat 复用该 spec，并在暂存目录构建后复制程序文件，避免清空用户数据。
更新后的 exe `--check` 返回 0，识别 8 条 Prompt，读取失败数为 0。更新前后 9 个
Prompt / 配置文件的 SHA-256 一致。

白色主界面和三个对话框使用 offscreen 平台渲染并检查。使用真实 Prompt 数据模拟
点击「大步开发」后，标题及正文一致。用户按 Esc 停止桌面自动操作后，未继续进行
桌面鼠标 / 键盘验证；新版主程序由用户自行打开。
